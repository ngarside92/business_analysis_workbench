## Business Analysis Workbench v9

Download `business_analysis_workbench_v9.html` from Releases and open the
downloaded file in a desktop browser. The app runs offline and requires
no installation or server.

The HTML opens with an illustrative RFI project and 24 populated workflows.
`RFI_Full_RTM_Workflow_Project.json` is a separate mock project you can load
through **Open project**.

Use **Export JSON** for a project backup or **Portable HTML** to save a
new standalone copy with your project data embedded.
